## Run locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Select a curriculum card to open its notes or example.

```bash
git clone https://github.com/AtharvBulkunde/HTML.git
cd HTML
```

You can also serve it locally with the VS Code **Live Server** extension for a convenient development workflow.

## Web page features

- Responsive layout for desktop, tablet, and mobile
- Navigation links to repository learning materials
- HTML code preview
- Curriculum cards and step-by-step learning path
- Lightweight scroll-reveal effects
- Accessible navigation labels and reduced-motion support
- No framework, build step, or runtime dependency
