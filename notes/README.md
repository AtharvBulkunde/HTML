## How to use these notes

1. Open a chapter and read its short explanations.
2. Type the examples into your own HTML file.
3. Refresh the browser after changing a tag or attribute.
4. Try the practice tasks before moving to the next chapter.

HTML provides structure. CSS controls presentation, JavaScript adds browser-side behaviour, and a backend is only needed when a project requires server-side processing, accounts, or database storage.
