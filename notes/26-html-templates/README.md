# HTML Templates

These are practical study notes for html templates. Read the idea, type the example into your own file, and change a value to see what happens in the browser.

## Topics

- Starter document
- reusable sections
- template element
- consistent markup

## Example

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML Templates</title>
</head>
<body>
  <main>
    <h1>HTML Templates</h1>
    <p>This is a small example to help me practise html templates.</p>
  </main>
</body>
</html>
```

## Practice

1. Type the example yourself.
2. Change the heading and paragraph.
3. Add one relevant element from the topic list above.
4. Preview it in a browser and check for errors.
5. Explain the concept in your own words.

## Remember

Use semantic HTML when an element has a clear meaning. Use CSS for visual styling and JavaScript for custom browser behaviour. Do not put passwords, API keys, or other secrets in HTML or JavaScript files.
