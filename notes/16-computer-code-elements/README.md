# HTML Computer Code Elements

These notes are written as a practical study guide. Read the short explanation, try the example in your own file, and then change the code to see how the browser responds.

## Topics in this chapter

- [code](#code)
- [pre](#pre)
- [kbd](#kbd)
- [samp](#samp)
- [var](#var)

---

## code

Code represents a fragment of computer code, such as a tag, variable, or short command.

```html
<p>Use <code>h1</code> for the main heading.</p>
```

## pre

Pre preserves whitespace and line breaks. It is often paired with code for formatted code examples.

```javascript
<pre><code>const message = 'Hello';
console.log(message);</code></pre>
```

## kbd

Kbd represents user input, commonly a keyboard shortcut.

```html
<p>Save with <kbd>Ctrl</kbd> + <kbd>S</kbd>.</p>
```

## samp

Samp represents sample output from a computer program.

```html
<p>Result: <samp>Build completed</samp></p>
```

## var

Var marks a variable name in a mathematical expression or programming context.

```html
<p>Area = <var>width</var> × <var>height</var>.</p>
```
